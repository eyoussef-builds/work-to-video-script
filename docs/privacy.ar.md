# الخصوصية والتعامل مع الأدلة

[English](privacy.md) · [الرئيسية](../README.ar.md)

الحزمة فيها تعليمات Markdown ومراجع وبيانات اختيارية لواجهة المساعد. مافيهاش برنامج لجمع التاريخ أو تتبع الاستخدام أو خادم أو بيانات دخول أو مسجل شاشة تلقائي.

## إيه اللي المساعد ممكن يقرأه؟

المهمة الحالية وملفات المشروع وتاريخه ونتائج التحقق والصور اللي بتتيحها له. النموذج أو المزوّد ممكن يعالج المحتوى حسب إعدادات البرنامج. التصوير يحتاج أدوات البرنامج والصلاحية المناسبة؛ المهارة نفسها ما تمنحش الوصول. المساعد السحابي ما بيرثش ملفات جهازك أو محادثات برامج تانية تلقائيًا.

## المخرجات الخاصة

الصور الأصلية وسجل الأدلة وربط المصادر بالمشاهد ممكن يكون فيها بيانات حساسة. احفظها في مجلد مخرجات خاص ومسموح للمشروع، خارج الملفات المنشورة أو المسجلة في Git. ما تصدّرهاش تلقائيًا مع المهارة أو التطبيق. ملف التفضيلات المحلي `references/local-profile.md` تخصيص خاص ويُستبعد من التوزيع.

جهّز نسخ صور منفصلة للمشاركة بعد المراجعة. راجع الصورة وبياناتها المرفقة: المفاتيح، ومعرّفات الحسابات، وأسماء أصحاب الرسائل ومحتواها غير المتعلق بالحكاية، والإشعارات، والفواتير، والمسارات الخاصة، والروابط وأكواد QR. القص وإخفاء البيانات ما يغيّروش سلوك الواجهة أو يختلقوا دليلًا. فحص النصوص وحده ما يضمنش خلو كل بكسل من بيانات حساسة.

## حدود المهمة وتأثير الخطوات

المراجعة تخص الشغل المكتمل المعتمد. خطة الديمو مش إذن بإرسال رسائل أو تعليقات عامة أو تعديل الإنتاج أو استدعاءات مدفوعة أو منح وصول جديد. المهارة بتقف قبل توليد الصوت أو الفيديو أو تسجيله أو نشره أو إعداد أتمتة اجتماعية. اعتماد السكريبت أو ذكر وعد ترويجي مش إذن تلقائي لنشر مستودع تاني خاص.

## إيه الموجود في الحزمة العامة؟

تعليمات قابلة لإعادة الاستخدام، وأدلة باللغتين، ومثال خيالي، وحالات مراجعة، ورسومات ترويجية. مافيهاش محادثات بناء حقيقية أو رسائل عملاء أو ربط حسابات أو صور لشغل خاص أو ملف تفضيلات صاحبها. الرسومات تشرح القدرات وليست دليلًا على مشروع فعلي.

احذف حزم المخرجات الخاصة لما ما تحتاجهاش، حسب سياستك. الحزمة ما بتثبتش خدمة احتفاظ أو حذف تلقائي. تكلفة المساعد وسياسات المزوّد منفصلة عن ترخيص MIT.
