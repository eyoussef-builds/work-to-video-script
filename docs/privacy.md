# Privacy and evidence handling

[العربية](privacy.ar.md) · [Home](../README.md)

This package contains Markdown instructions, references and optional agent UI metadata. It has no executable history collector, telemetry, bundled server, account credentials or automatic recorder.

## What the host can process

The agent may read the active task, relevant project files/history, verification records and screenshots you make available. Its model/provider can process this content according to your host configuration. Browser/app capture requires the host's tools and your existing authorization; this skill does not grant access by itself. A cloud agent does not inherit local files or other products' conversations automatically.

## Private outputs

Raw images, the evidence ledger and source-to-scene mappings can contain sensitive information. Store them in an allowed private project output directory outside public/committed files. Do not automatically export them with the reusable skill or commit them with your application. A local `references/local-profile.md` is private customization and must be excluded from redistribution.

Create separate reviewed image derivatives for sharing. Check pixels and metadata for credentials, account IDs, inbox participants, unrelated message content, notifications, billing details, private paths and URLs/QR codes. Cropping/redaction must not fabricate interface behavior or change the evidence being presented. A scanner cannot guarantee that every sensitive pixel is absent.

## Scope and side effects

The scan is limited to the approved completed task. Planning a demo does not authorize actual sends, public comments, production writes, paid calls or new access grants. The skill stops before voice/video generation, recording, publishing or social automation. Script approval and a promotional pledge are not automatic authorization to release another private repository.

## What the public package contains

Reusable instructions, bilingual guides, a fictional example, review cases and promotional illustrations. It contains no real build chats, customer conversations, account bindings, screenshots of private work or creator-specific local profile. The artwork explains capabilities and is not project evidence.

Delete private output packs when no longer needed, according to your own retention policy. This instruction package does not install a retention service. Host usage fees and provider data policies remain separate from the MIT license.
